<details>
<summary><b>What's actually running on this page</b></summary>

<br/>

The streak card, the 3D calendar and the snake are all generated by a
[workflow](../../actions) in this repo at 02:00 UTC+8 and served from the
`output` branch — no third-party image services, so nothing here can break
when someone else's free tier runs out.

The streak card is [~200 lines of Python](scripts/generate_streak.py) drawing
raw SVG, written after the hosted one started timing out.

</details>
